# Трассировка всех LLM-вызовов

Используется OpenTelemetry Python SDK, локальный JSONL SpanExporter.
Каждая попытка (успешная и ошибочная) создаёт span с моделью, этапом, версией
промпта, latency, токенами и безопасным кодом ошибки. Корневой span объединяет
запрос API / эксперимент. Повторы видны отдельно. Токены оплаченных невалидных
ответов не теряются. Для timeout без usage расход не объявляется известным нулём.

```powershell
$env:AI_TRACE_CONTENT='true' # только синтетический golden dataset
python -m ml.experiment --limit 2 --repeats 1
python -m ml.tracing.dashboard
```

Открыть http://127.0.0.1:8001 — раскрываются промпты и ответы, latency и usage.
Обновить страницу после новых вызовов. Дашборд читает последние 300 spans.
Для обычных пользовательских текстов `AI_TRACE_CONTENT=false` (значение по умолчанию):
сохраняются только метаданные, как требует политика лабы 2.

`AI_TRACE_PATH` задаёт путь, по умолчанию `logs/llm-traces.jsonl`; папка исключена из Git.
Дашборд предназначен только для localhost, без публичного размещения.
Файл трейсов для пользовательских данных нужно удалять по политике хранения 30 дней;
автоматическое управление сроком хранения в учебный сервис не входит.
