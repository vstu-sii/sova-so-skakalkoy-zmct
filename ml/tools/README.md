# resolve_weekday

Инструмент доступен только сценарию извлечения с календарной подсказкой.
Принимает ISO reference_date, имя IANA timezone и день недели на русском.
Возвращает объект с status и date. Дата в формате YYYY-MM-DD или null.
Ближайший день включает текущую дату. Если пользователь указал явное число
или неоднозначный контекст, диспетчер не вызывает инструмент.

Диспетчер проверяет имя и allowlist, заданный приложением. Текст анонса
и ответ модели не могут расширить права. Инструмент ничего не записывает,
не обращается к сети, файловой системе проекта или БД мероприятий.
Бюджет выполнения 200 мс, при отказе дата остаётся пустой и требуется
уточнение. Проверка таймаута покрывает асинхронную задержку; текущая
календарная операция синхронно выполняет только несколько вычислений.

Инструмент вызывается кодом перед генерацией, а вычисленная дата передаётся
модели как calendar_hint. Это управляемая интеграция, без свободного выбора
инструментов моделью. В тестовом AI API включается через
`AI_EXTRACTION_VARIANT=calendar`. По умолчанию используется baseline.
