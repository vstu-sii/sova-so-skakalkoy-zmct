# Contributing

Правила работы с репозиторием. Обязательны для всех участников команды.

## Ветки

Главная ветка — `main`. Она всегда в рабочем состоянии, туда **нельзя пушить напрямую**.

Вся работа — в отдельных ветках. Именование:

| Префикс | Когда использовать |
|---|---|
| `feature/product*` | Задачи Product / VO |
| `feature/ai*` | Задачи AI Engineer |
| `feature/delivery*` | Задачи Delivery |
| `feature/quality*` | Задачи Quality & Safety |
| `fix/*` | Исправление бага |

Правила:

- Ветка живёт максимум 2–3 дня. Если задача больше — разбей на части.
- Перед PR синхронизируйся с `main` через rebase.
  Две команды для синхронизации, иначе пуш отклонится:

  ```text
  git fetch origin
  git rebase origin/<имя-твоей-ветки>
  ```

- Один PR — одна задача.
