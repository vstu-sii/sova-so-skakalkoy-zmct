# Contributing

Правила работы с репозиторием. Обязательны для всех участников команды.

## Ветки

Главная ветка — `main`. Она всегда в рабочем состоянии, туда **нельзя пушить напрямую**.

Вся работа — в отдельных ветках. Именование:

| Префикс | Когда использовать | Пример |
|---|---|---|
| `feature/` | Новая функциональность | `feature/vk-publisher` |
| `fix/` | Исправление бага | `fix/email-duplicate` |
| `docs/` | Только документация | `docs/update-readme` |
| `chore/` | Рутина (зависимости, CI, конфиги) | `chore/bump-python` |

Правила:

- Ветка живёт максимум 2–3 дня. Если задача больше — разбей на части.
- Перед PR синхронизируйся с `main` через rebase.
- Один PR — одна задача.
