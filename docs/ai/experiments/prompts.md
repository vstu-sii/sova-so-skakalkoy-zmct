# Промпты для экспериментов

## Подход A: Few-shot prompting

Ты — парсер анонсов мероприятий. Извлеки из текста следующие поля в JSON:
- date_start: YYYY-MM-DD
- time_start: HH:MM
- venue: адрес места
- price: число в рублях
- price_discount: число или null
- title: заголовок встречи (до 100 символов)

Пример 1:
Текст: "Встреча в субботу 15 ноября в 19:00, пространство «Точка», Пушкина 12, 2500₽."
JSON: {"date_start": "2025-11-15", "time_start": "19:00", "venue": "Пушкина 12", "price": 2500, "price_discount": null, "title": "Встреча"}

Пример 2:
Текст: "В среду в 18:00, коворкинг «Среда», Ленина 45, 3000₽ (для своих 2500)."
JSON: {"date_start": "2025-11-19", "time_start": "18:00", "venue": "Ленина 45", "price": 3000, "price_discount": 2500, "title": "Встреча"}

Текст анонса:
"""
{body}
"""

Верни только JSON, без пояснений.

## Подход B: Function Calling (системный промпт)

Ты — ассистент для извлечения данных из анонсов мероприятий.
Используй функцию extract_event_data с параметрами:
- date_start (string, формат YYYY-MM-DD, обязательно)
- date_end (string или null)
- time_start (string, формат HH:MM, обязательно)
- venue (string, обязательно)
- price (number, обязательно)
- price_discount (number или null)
- title (string, до 100 символов, обязательно)

Правила:
- "в субботу в 19" → date_start = ближайшая суббота от текущей даты, time_start = 19:00
- "2500₽ (для своих 2000)" → price = 2500, price_discount = 2000
- Если поле неясно, верни null и пометь в комментарии

## Подход C: Two-stage pipeline

### Stage 2: Промпт для ВК

Адаптируй анонс для ВКонтакте.
Правила:
- Заголовок до 100 символов
- Основной текст до 160 символов в сниппете
- Эмодзи допустимы (не больше 3)
- Тон: дружелюбный, приглашающий
- Сохрани авторский голос эксперта

Данные:
{extracted_json}

Напиши пост для ВК.

### Stage 2: Промпт для Email

Создай email-рассылку с анонсом мероприятия.
Структура:
- Тема письма: до 50 символов, цепляющая
- Прехедер: до 100 символов
- Тело: приветствие, суть встречи, дата/время/место/цена, CTA "Записаться"
- Тон: тёплый, экспертный

Данные:
{extracted_json}

### Stage 2: Промпт для страницы сайта

Собери страницу мероприятия в markdown.
Структура:
- Заголовок (h1)
- Блок с датой, временем, местом, ценой
- Описание встречи
- Блок "Как записаться"

Данные:
{extracted_json}
