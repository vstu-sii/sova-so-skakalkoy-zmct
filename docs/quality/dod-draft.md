# Definition of Done — черновик

**Проект:** Один анонс — площадки и страница мероприятия
**Роль:** Quality & Safety (черновик), согласование — вся команда
**Статус:** черновик v0.1 (лаба 1), к согласованию до лабы 2
**Обновлено:** 2026-09-14

---

## 1. Что это

DoD — спека для автопроверки, а не декларация о намерениях. Каждый критерий сформулирован так, чтобы проверка давала один из трёх типов ответа:

- **есть/нет** — файл, поле, раздел существует;
- **число** — количество, доля, значение метрики;
- **ссылка** — URL на коммит, отчёт, успешный прогон.

Формулировки вида «качественно описано», «достаточно подробно», «проработано» в DoD не допускаются: их нельзя проверить, значит они не критерии, а мнение.

## 2. Общий DoD (любой артефакт команды)

| # | Критерий | Тип | Как проверяется |
|---|---|---|---|
| G1 | Артефакт лежит в репозитории по согласованному пути | есть/нет | `git ls-files` |
| G2 | В шапке указаны роль-владелец, статус и дата обновления | есть/нет | grep по шапке |
| G3 | Ссылка на артефакт есть в корневом `README.md` | ссылка | проверка битых ссылок |
| G4 | Артефакт прошёл ревью хотя бы одной смежной роли | ссылка | approve в PR |
| G5 | Открытые вопросы вынесены отдельным разделом, а не растворены в тексте | есть/нет | наличие раздела |

## 4. DoD фичи (начиная с лабы 3)

Применяется к любому изменению, которое влияет на выход системы.

| # | Критерий | Тип | Порог |
|---|---|---|---|
| F1 | Прогон метрик на golden dataset выполнен после изменения | ссылка | — |
| F2 | M2 (Critical Field Error Rate) не выросла относительно предыдущей версии | число | не выше baseline |
| F3 | M7 (Format Compliance) | число | 100% |
| F4 | M8 (Page Assembly Correctness) | число | 100% |
| F4a | M9 (Media Integrity) — картинки перенесены, порядок карусели сохранён | число | 100% |
| F5 | S1 (Injection Resistance) на adversarial-подмножестве | число | не ниже предыдущего прогона |
| F6 | S2 (Pre-publication Gate) | число | 100% |
| F7 | Отчёт метрик приложен к PR с указанием версии датасета и версии промпта | ссылка | — |

F3, F4, F6 — жёсткие: это детерминированные проверки, их падение означает дефект, а не статистическое колебание. F2 и F5 сравнительные, поэтому прогон без предыдущего отчёта для сравнения не считается выполненным.

---

## 5. Что НЕ входит в DoD

Чтобы не разрослось до неисполнимого списка:

- охваты и конверсия анонсов — не наша метрика;
- покрытие тестами кода — отдельная договорённость Delivery, к выходу системы не относится;
- художественное качество картинок и их генерация (целостность переноса — меряется, M9);
- работа с данными клиентов — таких данных в проекте нет.
