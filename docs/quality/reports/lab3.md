# Первый eval baseline — лабораторная 3

29 октября 2026. Quality & Safety. Живая Qwen 2.5 3B Q4_K_M в Ollama 0.40.13.
Исходная GPT-4o-mini из ADR-002 в этом прогоне не использовалась: см. ADR-006.

## Методика и воспроизведение

53 записи dataset v2 (44 исходных, 6 по отчёту лабы 1, 3 из живых ошибок baseline),
каждая по 3 раза: **159 реальных запросов на извлечение**. `needs_context` (2 записи × 3)
не входит в M1–M3 и основные quality-метрики; эти ответы сохранены отдельно в общем JSONL.
Первичный результат считается по всем попыткам, без выбора удачного повтора.

```sh
python -m tests.evals.run --dataset docs/quality/golden-dataset/v2.jsonl --split all --repeats 3 --output docs/quality/reports/lab3-full
```

Инструмент — pytest + детерминированные project scorers; тот же адаптер baseline, что и в API.
Все ответы, latency и токены: [JSONL](lab3-full/requests.jsonl), [CSV](lab3-full/usage.csv).
Версии, digest модели, хэш dataset, параметры и source SHA: [run.json](lab3-full/run.json).
Машиночитаемые метрики: [metrics.json](lab3-full/metrics.json).

В этом итоговом запуске открыт test split (22 записи × 3), доступ зафиксирован здесь и в run.json.
После просмотра test промпты не изменялись. Результаты относятся к проекции public Event,
а не ко всем полям старого dataset. Неподдерживаемые duration/format/speaker/media и
невместимые списки цен не получают фиктивный зачёт. Правила — в golden-dataset/README.md.

## Честные границы измерения

- M4/M5: без человека или калиброванного judge достоверно не посчитаны. Код импорта оценок готов,
  [manual-review.csv](manual-review.csv) содержит 18 реальных черновиков и SHA-256, но пустые оценки.
  Пустота не превращается в 0/100%. Команды заполнения и подсчёта — в tests/evals/README.md.
- M8: библиотека блоков page-composer отсутствует; API возвращает Markdown, полную сборку страницы не оценивали.
- M9: public API лабы 2 не принимает медиа; порядок/пропорции изображений не измерены.
- S2: в AI-сервисе нет публикационного метода. Подтверждение и запрет генерации draft проверены интеграционными тестами,
  но доли реальных публикаций без логов публикаций нет.
- RAG отсутствует, метрики поиска N/A. T1 до публикации с человеком не измерен.
- Доверительные интервалы по повторным ответам описательные: повторы одного примера коррелируют,
  их нельзя трактовать как 153 независимых новых анонса. Также показывается стабильность по уникальным ID.

## CI и значение порогов

`.github/workflows/evals.yml` запускает 18 unit/integration tests, затем живой mini-eval.
Закреплены Ollama release и digest весов; секреты и платный API не требуются.
JSONL/CSV/метрики сохраняются в Actions artifacts на 14 дней. Порог нарушен — exit 1, джоб красный.
Первый проверенный запуск: https://github.com/AlenKizimenko/sova-so-skakalkoy-zmct/actions/runs/40882229420 .

Bootstrap-пороги: E3/M7/S1 = 100%, M6 ≤20%. Начальная M2 mini равна 100% ошибок,
поэтому относительный предел M2 ≤100% не несёт сигнала: это явно плохая baseline,
не продуктовый допуск. После улучшения нужно зафиксировать более строгий предел M2.
Негативные тесты проверяют вычисление M2/M6 и отказ при нарушении порога.
Wilson-пороги сравнительной приёмки требуют следующего сопоставимого прогона и согласования команды;
первый baseline нельзя выдавать за сравнение с предыдущей версией.
Branch protection не изменялась: статус CI будет требовать merge только после настройки мейнтейнером.

## Что следует для продукта

Baseline технически работает, но ошибки фактов требуют обязательной сверки экспертом.
JSON Schema и отсутствие forbidden string не доказывают смысловую правдивость.
S1 считается консервативно: сбой обработки атаки не засчитывается как успешный ответ без injection.
Приоритеты следующей итерации: календарный резолвер, month-only → null, запрет адреса
из «как обычно», цена 0 для бесплатных событий, сохранение полного названия площадки.
Новые gd-live-001…003 добавлены из реальных ошибок без изменения исходных эталонов.
Генерация в offline эксперименте могла использовать неполные карточки; публичный API
по-прежнему требует подтверждения и не публикует ничего автоматически.
