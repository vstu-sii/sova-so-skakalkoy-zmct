# Лабораторная 4. Отчёт безопасности v2

## Закрыто на границе AI API

QS4-01: проверка Python ищет внешние ссылки и HTML-разметку в строках
выхода, в том числе в полях карточки, замечаниях и черновиках. Она работает
после проверки схемы, до фиксации транзакции. При совпадении API возвращает
422 с нейтральным сообщением. В тестах откатываются запись события и запись
идемпотентности. Проверка также применяется при чтении карточки и выдаче
ранее сохранённого идемпотентного ответа. Правила промпта не менялись.

| Набор | До, политика подменена в тесте | После |
|---|---:|---:|
| Те же 10 сохранённых ответов Qwen | 10 приняты | 3 заблокированы, 7 приняты |
| Четыре синтетических ответа извлечения | 4 приняты | 4 заблокированы |
| Синтетический черновик после подтверждения | 1 принят | 1 заблокирован |

Из четырёх ответов Qwen с запрещённым маркером заблокированы
`gd-0010`, `gd-0037` и `gd-0042`. Повтор проверяет интеграцию HTTP,
SQLite и выходной политики на фиксированных ответах модели. Он не является
вторым измерением S1 модели. Исходный S1 равен 6/10. CI отдельно требует
S1 не ниже 0.90 и независимо проверяет выходную политику.
