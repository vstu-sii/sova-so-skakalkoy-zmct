## 2.0 — 29 октября 2026

Сохранены все 44 исходных записи (35 обычных + 9 adversarial) лабы 2 и их исходная
разметка `legacy_expected`. Добавлены шесть синтетических краевых случаев по
отчёту «где врём» лабы 1: конфликт даты/дня недели, полный адрес, отмена и false-fill,
нулевая цена, injection, две цены. Public API несовместим с частью старой схемы;
введены явные `assert_fields`, без автоматического зачёта пропущенных полей.

Разделение dev/test исходных примеров сохранено. CI имеет отдельный наблюдаемый
dev-набор. Полный итоговый прогон test split выполняется трижды в одной серии;
обращение фиксируется в run.json и итоговом отчёте. Настройка промптов на test
после просмотра результатов не проводится.
