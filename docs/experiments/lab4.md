# Лабораторная 4. Итерации извлечения и A/B

Модель Qwen 2.5 3B через локальную Ollama. Сравнивались четыре конфигурации
на одних и тех же шести dev-примерах из фиксированного CI-набора, один
запрос на пример в каждой конфигурации. Это отбор кандидата для следующего
этапа, выборка мала и пересекается с примерами из отчёта «где врём».
Отдельный тестовый сплит в этой итерации не использовался.

Промпт v2 адресует месяц без конкретного дня, неизвестный прошлый контекст,
потерю названия площадки, бесплатный вход, смешивание двух тарифов и
копирование внедрённых инструкций. Календарный вариант добавляет
детерминированное разрешение одного явного дня недели. Компактный вариант
убирает копию JSON Schema из сообщения, сохраняя параметр `format` Ollama.
Поиска документов в этом сценарии нет.

| Вариант | M2 ↓ | M3 ↑ | M6 ↓ | E3 ↑ | S1 ↑ | Токены входа | Токены выхода | p95, с |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| A: исходный промпт | 6/6 | 0/6 | 3/20 | 6/6 | 1/1 | 5283 | 2328 | 12.87 |
| B: промпт v2 | 3/6 | 0/6 | 3/20 | 6/6 | 1/1 | 5517 | 2102 | 10.35 |
| C: v2 + календарь | 2/6 | 0/6 | 3/20 | 6/6 | 1/1 | 5533 | 2103 | 10.97 |
| D: C без копии схемы в промпте | 4/6 | 0/6 | 2/20 | 6/6 | 1/1 | 2419 | 2015 | 12.79 |

M2 — критические ошибки, M3 — полностью верные размеченные поля,
M6 — заполнение неизвестных полей, E3 — успешная обработка,
S1 — проверка запрещённых строк на одном примере.

- B_vs_A: порог пройден.
- C_vs_B: порог пройден.
- D_vs_C: порог не пройден.

Для отбора требуется улучшение хотя бы одной из M2, M3, M6, E3, S1
без ухудшения остальных метрик из этого списка. Для сокращения контекста
допустимо равенство этих метрик при меньшем
числе входных токенов. Среди кандидатов выбран **C: v2 + календарь**.
У A критических ошибок 6/6, у выбранного варианта
2/6. Полностью верные карточки у выбранного варианта:
0/6. По M1 у C хуже заголовок (0/4 против 2/4 у A) и регистрация
(0/2 против 2/2 у A). Вариант C выбран для следующей проверки, поскольку
лучше извлекает критические поля на dev-наборе. В AI API он доступен для
проверки через `AI_EXTRACTION_VARIANT=calendar`. Режим по умолчанию
использует A. Кандидат D уменьшил вход с 5533 до 2419 токенов,
но число критических ошибок выросло с 2/6 до 4/6.

Варианты сохранены для воспроизведения, а конфигурации, не прошедшие
критерий, исключены из выбора. Эксперимент не меняет конфигурацию Delivery.

Команда для повторного прогона из корня репозитория при запущенной Ollama
с загруженной моделью:

```bash
python -m ml.prompts_v2.ab --output docs/experiments/lab4-run
```

Папка `lab4-run` содержит ответы JSONL, токены CSV, параметры среды, метрики,
сводку выбора и отдельный повтор с кэшем. Ноутбук
`lab4-experiments.ipynb` читает эти файлы без новых обращений к модели.
Прогон последователен, поэтому задержка может зависеть от прогрева.
Результаты относятся к AI baseline 3B. Delivery использует другой API и 1.5B.
