29 октября 2026. AI Engineer. Фактический прогон, не расчёт и не mock.

Основная модель ADR-002 недоступна из-за отсутствия API-баланса. Согласованный
локальный вариант описан в ADR-006: **Qwen 2.5 3B Q4_K_M**, Ollama **0.40.13**,
RTX 3050 Laptop 4 ГБ, RAM 16 ГБ. Digest весов:
`357c53fb659c5076de1d65ccb0b397446227b71a42be9d1603d46168015c9e4b`.
Результаты нельзя приписывать GPT-4o-mini или Qwen 14B.

## Воспроизведение

Окружение — [lab3-setup.md](lab3-setup.md). Одна команда:

```sh
python -m ml.experiment --dataset docs/golden-dataset/v1.jsonl --split dev --limit 6 --repeats 1 --generate --output docs/experiments/lab3-run
```

Приложение: [выполненный ноутбук](lab3-experiments.ipynb).
Сырые ответы и usage: [requests.jsonl](lab3-run/requests.jsonl).
Экспорт на запрос: [usage.csv](lab3-run/usage.csv).
Хэш датасета, настройки и версия кода: [run.json](lab3-run/run.json).

Каждый запрос — извлечение + три отдельных генерации: **6 запросов, 24 LLM-вызова**.
Генерация неполных карточек здесь допускается только как offline-эксперимент;
публичный API запрещает её до подтверждения карточки. Выходы — учебные черновики,
а не опубликованные тексты. RAG и поиск отсутствуют, метрики retrieval — N/A.

Нулевая API-плата не означает нулевую полную стоимость: электричество и
оборудование не оценены. p95 на шести запросах — описательная статистика малой
выборки, не SLA. Первый запрос включает холодную загрузку; последующие — тёплые.
Очередь нескольких пользователей и время человека до публикации не измерены.

## Где baseline ошибается

| Пример | Фактическая ошибка |
| --- | --- |
| gd-0001 | «в субботу» от 14.11.2025 стало 19.11 вместо 15.11; потеряно слово «Пространство» |
| gd-0002 | Пропала конечная дата серии; «Место как обычно» стало значением venue |
| gd-0003 | Из указания месяца придуманы первое и последнее число месяца |
| gd-0004 | При неизвестном прошлом контексте придуманы 18:00 и полный адрес |
| gd-0005 | Не извлечены относительная дата и нулевая стоимость бесплатного вебинара |
| gd-0006 | Упрощено название адреса; способ оплаты ошибочно стал способом регистрации |

Итог: валидный JSON и успешный HTTP **не доказывают фактическую точность**.
На пяти сравнимых примерах (без needs_context) хотя бы одно критичное поле
неверно в **5/5**, все размеченные поля верны в **0/5**. Это точка отсчёта плохого
качества, а не допуск к публикации. Проекция старого golden dataset и исключённые
поля явно описаны в `ml/dataset.py`; venue сравнивается без адресной пунктуации,
но потеря названия площадки остаётся ошибкой.

Для продукта: локальная 3B достаточна для запуска инженерного контура и измерений,
но автоматическая публикация её предложений неприемлема. Сохраняем обязательное
уточнение и подтверждение экспертом. Следующая итерация: детерминированные
относительные даты, запрет выдумывать даты из месяца и адрес из «как обычно»,
извлечение нулевой цены и полная проверка исходного адреса. После этого — новый
prompt_version и сравнительный прогон, без изменения эталонов под модель.

Полный первый eval и CI находятся в ветке `feature/quality_lab3`.
Часть ошибок использована для трёх новых регрессионных примеров dataset v2.
Промпты не подстраивались под test split после просмотра итогового прогона.

Техническая оговорка: после успешных шести запросов экспорт Git-метаданных
остановился из-за ownership-проверки sandbox. JSONL и CSV сохранились; run.json
восстановлен без повторных LLM-вызовов, это отмечено внутри файла. Экспортёр
исправлен через доверие только к текущему пути в конкретном вызове Git;
глобальная Git-конфигурация не менялась.
