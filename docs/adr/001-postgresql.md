# ADR 001: PostgreSQL как база данных

## Статус
Принято

## Контекст
Платформе нужно хранить экспертов, мероприятия, страницы, публикации и подписчиков. Схема гибкая: у разных мероприятий могут быть разные поля. Нужны транзакции и целостность данных.

## Решение
Использовать PostgreSQL 16.

## Альтернативы
- MongoDB — гибкая схема, но слабая консистентность и сложнее с транзакциями.
- MySQL — популярна, но хуже поддержка JSON и полнотекстового поиска.
- SQLite — не подходит для продакшна с конкурентными запросами.

## Последствия
+ ACID-транзакции, JSONB для гибких полей, надёжность.
+ Хорошо работает с SQLAlchemy и FastAPI.
− Нужен отдельный контейнер в Docker.
− Схему нужно проектировать заранее.
