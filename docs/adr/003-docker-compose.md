# ADR 003: Docker Compose для dev-среды

## Статус
Принято

## Контекст
Разработчику нужно поднимать 6+ сервисов (БД, 4 сервиса, фронтенд) локально. Ручная установка и настройка каждого — часы работы и расхождения в окружении.

## Решение
Использовать Docker Compose. Одна команда `docker compose up -d` поднимает всю систему.

## Альтернативы
- Ручная установка — долго, «у меня работает, у тебя нет».
- Kubernetes — избыточно для локальной разработки.
- Podman — альтернатива, но меньше инструментов и документации.

## Последствия
+ Одна команда для запуска всего.
+ Одинаковое окружение у всех участников.
+ Легко добавить новый сервис.
− Docker Desktop на Windows требует ресурсов.
− Нужно базовое понимание Docker.
