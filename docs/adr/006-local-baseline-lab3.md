# ADR-006: локальная baseline для лабораторной 3

Дата: 29 октября 2026. Статус: принято для учебного прогона с согласия пользователя.

ADR-002 находится в `docs/model-candidates.md` ветки `ai_lab2`. Его основной маршрут
GPT-4o-mini недоступен для этого прогона: проверочный запрос вернул HTTP 429,
`credit_balance_exhausted`, `insufficient_quota`. Пользователь не может пополнить
API-баланс и согласовал локальную Qwen 2.5 3B вместо облачной модели.

Выбор: `qwen2.5:3b` в Ollama, temperature=0, Structured Outputs по JSON Schema,
контекст 8192, output до 1600 токенов. Точный digest и версия runtime фиксируются
в артефактах запуска. Это отдельный вариант baseline, а не измерение GPT или Qwen 14B.

На компьютере 16 ГБ RAM и NVIDIA RTX 3050 Laptop с примерно 4 ГБ VRAM.
3B выбран для ограниченной памяти; 14B не объявляется невозможным, но требует
большего объёма памяти/выгрузки на CPU. Качество 3B не переносится с крупных моделей.
Веса модели около 1,9 ГБ; стоимость токенов внешнего API равна нулю, расходы
оборудования и электричества не измерены. Цена полного владения не равна нулю.

Локальный call timeout увеличен до 120 с, deadline этапа — 245 с, операции API —
600 с. Это осознанное отклонение от облачных 20/60 с из лабы 2, а не доказательство
соответствия продуктовой задержке. Генерация каналов последовательная, чтобы не
переполнять VRAM. Экономичная модель не включена; запрос economy получает шаблоны.

RAG отсутствует: retrieval-метрики N/A, никакого смешивания поиска с ответом.
Модель не имеет инструментов публикации и доступа к аккаунтам площадок.

Источники: [веса Qwen](https://ollama.com/library/qwen2.5:3b),
[Structured Outputs Ollama](https://docs.ollama.com/capabilities/structured-outputs),
[установка Windows](https://docs.ollama.com/windows).

Ограничения: public Event из лабы 2 несовместим со старым golden schema по ценам,
длительности, формату и медиа. `ml/dataset.py` явно проецирует только сравнимые поля.
Это не полная M1/M3 исходной карты качества; в отчёте обязательно указывать область.
Семантическая правдивость свободного текста не доказывается JSON Schema и требует
ручной проверки. Внедрение в production этим решением не разрешается.
