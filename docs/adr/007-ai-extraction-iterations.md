# ADR-007. Итерации извлечения и стоимость повторов

Статус: выбран кандидат для дальнейшей проверки. Промпты и календарный
инструмент доступны в эксперименте. Серверный кэш включается отдельным флагом.

Контекст: ошибки даты, площадки и выдуманных значений из `docs/quality/eval-report-1.md`.
Проведено сравнение на общем dev-наборе с теми же метриками, что в лабораторной 3.

Решение: выбрать C: v2 + календарь по измеренным метрикам. Зафиксировать
кандидатов и сырые прогоны. Сохранить текущий режим API по умолчанию до
подтверждения на независимой выборке. Календарный resolver вычисляет дату
без прав записи. Кэш ограничен одним процессом и областью владельца.

## Цена решения

Тестирование новых промптов требует парных прогонов и времени локальной
модели. На коротком наборе возможна подгонка под примеры. Календарный
resolver поддерживает только одно явно распознанное упоминание дня недели.
Кэш хранит до 128 результатов и исходные ключи в оперативной памяти.
Необходимы наблюдение за реальной частотой повторов и проверка времени ответа
перед включением. Денежная экономия сверх нулевой внешней платы не установлена.
