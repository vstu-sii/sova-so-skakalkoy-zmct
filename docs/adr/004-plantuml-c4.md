# ADR 004: PlantUML + C4 для архитектурных диаграмм

## Статус
Принято

## Контекст
Нужны диаграммы архитектуры, которые можно версионировать, ревьюить и менять как код. Бинарные форматы (Figma, PNG) не подходят.

## Решение
Использовать PlantUML с библиотекой C4-PlantUML. Диаграммы хранятся как `.puml`-файлы в `docs/architecture/`.

## Альтернативы
- Figma / Miro — визуально удобно, но бинарные форматы, не diff-ятся в Git.
- draw.io — XML громоздкий, плохо ревьюится.
- Mermaid — проще, но менее выразителен для C4.

## Последствия
+ Диаграммы как код: diff, ревью, версионирование.
+ C4-PlantUML даёт готовые шаблоны для Context и Container.
+ Рендерится в PNG/SVG одной командой или онлайн.
− Нужен рендерер: плагин VS Code или онлайн-редактор.
− Кривая обучения синтаксису PlantUML.
