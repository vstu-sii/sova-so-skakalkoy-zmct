# Стоимость извлечения. Лабораторная 4

Измерено на Qwen 2.5 3B через Ollama. Внешняя плата за токены — **0 ₽**
до и после. Полная стоимость владения не измерялась: нет замера
электроэнергии и тарифа на оборудование.

| Сценарий | До | После |
|---|---:|---:|
| Входные токены на одинаковых шести примерах, C → D | 5533 | 2419 |
| Вызовы модели на двух одинаковых запросах, без кэша → холодный + попадание | 2 | 1 |
| Сумма входных и выходных токенов на этих двух запросах | 2380 | 1190 |
| Внешняя плата за два запроса | 0 ₽ | 0 ₽ |

Компактный промпт не прошёл
критерий сохранения качества и экономии входных токенов относительно C.
Сравнение вариантов и решение сохранены в `docs/experiments/lab4-run/comparison.json`.

Кэш проверен на повторе `gd-0001` в выбранном варианте
`C_calendar`. Попадание повторяет сохранённую карточку, имеет ноль
провайдерских токенов и заняло 0.081 мс в локальном прогоне.
Кэш включается для AI API переменной `AI_EXTRACTION_CACHE=1`.
По умолчанию отключён. Ключ учитывает владельца из авторизации,
провайдера, модель, текст, дату отсчёта и зону. Срок выдачи 300 секунд,
лимит 128 записей на процесс. При рестарте кэш очищается. Ошибки модели
не записываются. Записи с истёкшим TTL больше не выдаются.

Пара запросов иллюстрирует эффект при точном повторе. Экономия на реальном
потоке зависит от доли попаданий, которую здесь не измеряли.
