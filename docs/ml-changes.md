# Изменения AI-части по итогам месяца

| Решение | Основание | Цена решения |
|---|---|---|
| Выбор C: v2 + календарь | Парный dev-прогон в `docs/experiments/lab4.md` | Дополнительный прогон на независимой выборке перед выкладкой. Шесть примеров не дают оценки генеральной совокупности. |
| Календарный инструмент с ограниченным доступом | Ошибки относительных дат | Поддерживается узкий набор фраз. Неоднозначные даты требуют уточнения. Нужна поддержка правил распознавания. |
| Опциональный кэш извлечения | Повтор убирает один вызов модели в измеренном сценарии | Память процесса и краткосрочное хранение исходного текста, изоляция по владельцу. Нет общего кэша между воркерами. |
| Удаление дублирующей схемы как эксперимент | Проверка расхода контекста | Результат привязан к Ollama и текущей модели. При замене модели нужен новый парный прогон. |

ADR: `docs/adr/007-ai-extraction-iterations.md`.
Решение по локальной модели из ADR-006 действует для измеряемого AI API.
Подключение этих экспериментов к Delivery требует отдельной интеграции.
