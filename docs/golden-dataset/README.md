# Golden dataset v1

**Проект:** Один анонс — площадки и страница мероприятия
**Статус:** v1 — на согласовании 
**Обновлено:** 2026-10-14

Эталонные пары «вход → верный ответ». Пишутся до кода и по use cases.

## 1. Состав

| Файл | Что | Записей |
|---|---|---|
| `v1.jsonl` | основная выборка (dev ≈70% / test ≈30%) | 35 |
| `adversarial.jsonl` | инструкции внутри входа, целиком `test`, считается отдельно (S1, S2) | 9 |
| `assets/` | картинки для `media` (в репозитории пока нет, см. §8) | — |

Всего **44** пары (требование: 30–50). Валидатор: `python scripts/validate_golden.py` — сейчас 0 ошибок.

**Источник записей** (поле `source`): `draft` — 10 (из лабы 1), `synthetic` — 34 (написаны QS по типовым анонсам), `archive` — **0**. Пока `archive = 0`, цифры метрик на этом наборе — оценка механики, а не качества на реальных анонсах эксперта.

**Разделение:** `dev` (25 записей, ~70%) — на ней AI Engineer крутит промпты. `test` (10 записей, ~30%) — закрытая, открывается только перед сдачей лабы. `adversarial.jsonl` целиком в `test`.

## 2. Use cases

В репозитории нет отдельного `docs/use-cases.md`, поэтому здесь рабочий список. Product подтверждает или правит его (критерий P6 в DoD); при правке перепривязывается поле `uc`.

| UC | Сценарий | Записей |
|---|---|---|
| UC-01 | Эксперт подаёт полный анонс, получает комплект (ВК, письмо, страница) | 12 |
| UC-02 | Анонс неполный: система возвращает `null`, а не догадку | 9 |
| UC-03 | Относительные даты: «в субботу», «завтра», «на следующей неделе» | 7 |
| UC-04 | Сложная цена: несколько ставок, донат, бесплатно | 6 |
| UC-05 | Онлайн и гибрид, ссылка вместо адреса | 8 |
| UC-06 | Многодневное мероприятие, серия встреч | 4 |
| UC-07 | Карусель из нескольких картинок | 6 |
| UC-08 | Перенос или отмена ранее объявленной встречи | 3 |
| UC-09 | Публикация только после проверки (S2) | через `attack.must_not_call` |
| UC-10 | Вредоносная инструкция внутри анонса или комментария | 9 |

Запись может относиться к нескольким UC, поэтому сумма больше 44.
