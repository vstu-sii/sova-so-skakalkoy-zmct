# ADR-0004. Страница мероприятия собирается из фиксированной библиотеки блоков

Статус: предложено
Дата: 2026-10-15
Автор: Product / VO
Касается: сервис сборки страницы, контракт с данными мероприятия

## Контекст

Страница мероприятия — один из трёх выходов системы. Её содержимое должно совпадать с постами и обновляться при правке.

Модель могла бы генерировать разметку страницы целиком, подбирая оформление под конкретное мероприятие.

## Решение

Страница собирается из заранее свёрстанной библиотеки блоков: заголовок, время и место, цена, описание, запись. Система решает, какие блоки включить и какими значениями их заполнить, но не создаёт новые блоки и не генерирует вёрстку.

Блок, для которого нет данных, не выводится. Плейсхолдеров и надписей «не указано» на странице не бывает.

## Альтернативы

**Генерация разметки моделью.** Отклонено: вёрстка становится недетерминированной, проверить её автотестом нельзя, а страница при каждой перегенерации выглядит по-новому. Для сценария с правками это неприемлемо — участник, вернувшийся по старой ссылке, должен увидеть ту же страницу с исправленными данными, а не другую страницу.

**Один фиксированный шаблон без вариативности.** Отклонено: мероприятия без цены или без адреса вынуждали бы показывать пустые разделы.

## Цена решения

Каждый новый тип содержимого требует работы верстальщика: система не может показать то, подо что нет блока. Серия встреч с расписанием по дням, карта проезда, блок с отзывами — всё это сейчас показать нечем.

Оформление страниц у всех мероприятий одинаковое. Эксперт не может сделать свою страницу непохожей на чужую, и возможности подстроить её под свой стиль у него нет.

Правила выбора блоков — это код, который надо писать и поддерживать отдельно от генерации текстов.

## Последствия

- Метрика M8 из `docs/quality/success-criteria.md` проверяет состав блоков и отсутствие пустых плейсхолдеров автотестом.
- В UC-04 альтернатива 3а описывает поведение при отсутствующем значении.
- Запросы вида «а можно добавить на страницу…» решаются расширением библиотеки, а не правками в промпте.
