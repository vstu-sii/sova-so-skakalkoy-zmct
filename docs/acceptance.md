**DoD инкремента** — задача принята, если выполнено всё:

| # | Критерий | Как проверить |
|---|---|---|
| I1 | Работает на стенде, а не только локально | Показ на https://tanya-lab.88-87-92-145.sslip.io/ или ссылка на прогон CI |
| I2 | Соответствует критерию готовности пункта скоупа | Колонка «Критерий готовности» в `docs/mvp-scope.md` §2 |
| I3 | Тест или eval, который упадёт при регрессии | Ссылка на тест / job в CI |
| I4 | Нет демо-данных и заглушек под видом результата | Ответ `not_implemented`/`TODO`/константа ≠ успех |
| I5 | Тестовый канал помечен как тестовый | Интерфейс и документация |
| I6 | Общий DoD артефакта: G1, G4, G6, G7 из `docs/quality/dod.md` | PR, ревью, ссылки, отсутствие секретов |

**Решения по задаче:** ✅ принято → `done` в `tasks.csv` · ⚠️ принято с отклонением → `done` + новая задача на отклонение · ❌ не принято → обратно в `doing`, остаток по оценке владельца.

**Отклонение** записывается строкой «что не так → задача ID → владелец → срок». Без ID задачи отклонение не считается записанным.

Черновики под каждую площадку не генерируются: пост собирается из полей. Время T1 не измерено. На проде — версия без публикации |
| **2. Правка времени или места запускает цикл заново** | **Нет** | Изменить время или место опубликованного мероприятия в продукте нельзя: нет ни API, ни экрана правки. North Star = 0% (`docs/north-star.md`) | UC-02 целиком: D-08, D-09, правка поста ВК, письмо-уведомление |
| **2а. Опечатки после публикации** | **Нет — вне MVP** | Решение 12.11: UC-03 вырезан (`docs/mvp-scope.md` C1) | Вернуть после Demo Day |
| **3. Нет страницы мероприятия** | **Частично** | В `v1.0.0-demo` у мероприятия постоянный адрес `/event/{id}`; участник открывает страницу, вводит имя и email, получает «Вы успешно записались» с номером заявки; повтор того же email → «Вы уже записаны» | На проде (`main`) страница ещё на демо-объекте, регистрация — заглушка: нужен merge `delivery_lab5` и деплой |
| **4. Разный язык площадок** | **Нет** | Пост ВК и письмо собираются из одних и тех же полей события, без адаптации тона | Генерация черновиков есть только в AI API (`backend/`), путь Delivery её не вызывает |
| **5. Нет помощника — всё на памяти** | **Нет — вне MVP** | Планировщик и напоминания — не-скоуп (`docs/product/roadmap.md` §2) | — |

**Итог:** из 4 болей, которые MVP обещал закрыть (1, 2, 3, 4), — 2 частично, 2 нет. Главная, подтверждённая двумя респондентами боль 2 — **не закрыта**.
