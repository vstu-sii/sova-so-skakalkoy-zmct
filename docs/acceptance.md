**DoD инкремента** — задача принята, если выполнено всё:

| # | Критерий | Как проверить |
|---|---|---|
| I1 | Работает на стенде, а не только локально | Показ на https://tanya-lab.88-87-92-145.sslip.io/ или ссылка на прогон CI |
| I2 | Соответствует критерию готовности пункта скоупа | Колонка «Критерий готовности» в `docs/mvp-scope.md` §2 |
| I3 | Тест или eval, который упадёт при регрессии | Ссылка на тест / job в CI |
| I4 | Нет демо-данных и заглушек под видом результата | Ответ `not_implemented`/`TODO`/константа ≠ успех |
| I5 | Тестовый канал помечен как тестовый | Интерфейс и документация |
| I6 | Общий DoD артефакта: G1, G4, G6, G7 из `docs/quality/dod.md` | PR, ревью, ссылки, отсутствие секретов |
| I7 | Если меняет сценарий — обновлён UC | Ссылка на diff в `docs/use-cases/` |

**Решения по задаче:** ✅ принято → `done` в `tasks.csv` · ⚠️ принято с отклонением → `done` + новая задача на отклонение · ❌ не принято → обратно в `doing`, остаток по оценке владельца.

**Отклонение** записывается строкой «что не так → задача ID → владелец → срок». Без ID задачи отклонение не считается записанным.
